API (Node + Express + MongoDB)
What you will build
Y ou will build a small Library API: a server that keeps a list of books. There is no website.
Y ou will talk to your server using a tool called Postman.
The books are saved in a real database (MongoDB Atlas), so they are still there after you
stop and restart the server .
At the end you will have 6 working URLs: see all books, see one book, add a book, change a
book, delete a book, and filter the books.
Everything goes in one file, server.js. Y ou do not need to split your code into other files.
Before you start
Node.js and VS Code are installed. Check in a terminal: node --version
Postman is installed (free from postman.com).
Y ou have a GitHub account.
Y ou can sign up for a free MongoDB Atlas account (you will do this in Step 2).
How to work
1. Do the steps in order . Do not skip ahead.
2. After every step, run your server and test it in Postman. Compare what you see with
the Expected result.
3. Every time you change your code, stop the server with Ctrl + C and start it again
with node server.js.
4. If something does not work, read the Hint, then check Common mistakes near the
end.
